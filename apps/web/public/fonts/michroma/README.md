# Michroma Regular

Source: https://github.com/google/fonts/tree/main/ofl/michroma
Downloaded from the Google Fonts repository on 2026-10-07.
Copyright 2011 The Michroma Project Authors.
License: SIL Open Font License 1.1; see OFL.txt.

Michroma-Regular.woff is a lossless WOFF conversion of the source TTF using
fontTools. Glyph outlines and font metadata are unchanged. It is locally
hosted and used for ClearSig's public and app headings. Body copy, amounts, addresses
and controls retain the compact system font. No build-time or runtime font-service call.
