# Signature C background

Original ClearSig artwork exported from the authored SVG geometry in
`src/features/landing/ui/SignatureStage.tsx`. It preserves the approved C material
and is used as a static, low-contrast decorative background on app/public-product
surfaces. No external image service, script, remote reference, or WebGL runtime.
The landing keeps the interactive SVG; the app uses this cacheable asset to avoid
adding the geometry and its scroll handler to authenticated JavaScript bundles.
